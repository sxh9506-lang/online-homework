# Online Homework

面向教师与学生的在线作业网页系统。当前目标是在 **3 个工作日内交付可试用 MVP**，先验证一条端到端闭环：

1. 教师创建班级、布置并发布作业；
2. 学生查看本班已发布作业并上传提交；
3. 学生可重交，系统保留每个版本并标记逾期提交；
4. 教师批改并发布评分/反馈；
5. 学生查看自己的已发布反馈。

技术方向已确定为 **Java 25、Spring Boot 模块化单体、REST API、PostgreSQL、Spring Security、Spring Data JPA、Flyway**。产品规划中的文件存储为私有对象存储；服务端完成对象级授权后才发放短时签名上传/下载地址。MVP 规划中每个作业和每次提交各限 1 个附件，单个附件最大 **20 MiB（20,971,520 字节）**。这部分是后续产品规划，不代表当前演示版已配置附件存储。

## 当前免费演示版

- 演示只使用虚构数据；不要提交真实学生/教师信息或真实作业文件。
- 首发暂不开放附件上传；当前演示版的附件下载和文件校验也暂不可用，前端相关控件会显示禁用状态。
- 演示环境不启用付费存储档、不连接 Cloudflare R2 或其他附件存储。不要尝试上传附件。

学生先注册/登录；教师在自己的班级里按学生登录邮箱精确添加已有账号，没有账号时提示先注册。首版不发邀请邮件、不提供自助入班码，教师可以移除成员。测试环境使用预置测试账号；接入真实学生前必须验证登录邮箱。

带附件的提交采用两阶段上传：创建记录必须带 `Idempotency-Key`，同一学生、作业和 key 重试返回同一上传记录；上传完成接口先校验对象，再生成不可覆盖的提交版本。逾期按首次校验成功的 UTC `completedAt` 判定：等于截止时刻算按时，仅大于截止才逾期。对象未到齐返回可重试的 `UPLOAD_NOT_READY`，不产生可见版本；重复完成不重复计版本。

接口、模块边界与未决实施项见 [MVP 契约](docs/mvp-contract.md) 和 [OpenAPI 规范](docs/openapi.yaml)。

## 进度

项目刚启动。产品范围、模块/API 边界和 3 日交付计划正在通过 PR 固化；随后并行推进 API/数据库、网页主流程、验收用例与 CI/测试环境配置。以端到端可试用为优先，后续按试用反馈迭代。

## 非目标

首版不做家长端、移动 App、批量导入、通知、统计报表或自动判题。

## 安全提醒

本仓库当前为公开仓库。这里只提交通用源代码和文档；禁止提交真实学生/教师数据、账号密码、API 密钥、对象存储凭据或真实作业附件。示例账号只能使用本地开发专用的虚构数据。

## 协作方式

按产品/架构、后端、前端、测试、运维分开提交 PR。每个 PR 应聚焦单一工作流或组件，先过自动检查再集成，避免多人直接改动同一文件。
