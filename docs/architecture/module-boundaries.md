# 模块边界与技术约束

## 目标形态

Java 25 + Spring Boot 模块化单体，REST API，PostgreSQL；采用 Spring Security、Spring Data JPA 与 Flyway。首版不拆微服务、不引入消息队列。所有业务数据由一个应用部署和一个数据库事务边界管理，模块以 Java 包与应用服务边界隔离。

建议运行拓扑：浏览器 → HTTPS 网关/同域前端 → Spring Boot API → PostgreSQL；附件经 API 权限校验后使用短时签名 URL 与私有对象存储交换。对象存储桶不可公开，测试环境与生产凭据通过环境变量/秘密管理注入，不写入仓库。

## 短期演示数据库约束

- 短期演示目标选用 Render 免费 PostgreSQL：1 GB，创建后 30 天到期、无备份，到期后有 14 天宽限期再删除。
- 这是临时演示方案，不代表生产数据库或耐久备份。只使用虚构演示/测试数据；不得放真实学生资料，也不得存放任何唯一副本。
- 当前工作只记录已确认方案，不创建 Render 数据库或其他云资源。

## 模块

| 模块 | 职责 | 关键数据/规则 |
|---|---|---|
| `identity` | 注册、登录、邮箱验证状态、当前身份与角色 | `User`、`TEACHER`/`STUDENT`；密码仅保存安全哈希；真实学生访问前要求邮箱已验证。 |
| `classroom` | 教师班级、成员关系、班级时区 | 教师只能操作自己的班级；教师按精确登录邮箱添加现有学生；可移除成员；无自助入班码。 |
| `assignment` | 作业草稿、编辑、发布、截止/关闭和作业附件 | 草稿教师可见；学生只见所属班级已发布作业；截止时间持久化 UTC，展示使用班级 IANA 时区。 |
| `submission` | 上传意图、提交版本与逾期判定 | 上传完成并通过服务端校验后才分配版本号和 UTC `completedAt`；`late = completedAt > dueAt`，相等按时；重交追加版本，不覆盖旧版本；同一 Idempotency-Key 幂等。 |
| `grading` | 批改草稿、发布结果与历史 | 每次批改追加记录；学生仅可读取当前已发布结果；未发布评分/反馈不泄漏。 |
| `attachment` | 私有存储适配、上传/下载签名、文件约束 | 每作业/提交最多 1 个附件，<=20 MiB（20,971,520 字节），允许类型白名单；对象 key 由服务端生成；签名之前再做对象级授权。 |
| `common` | 稳定错误模型、时间/ID、审计字段与 API 基础设施 | UUID；业务错误使用稳定 `code`；统一 UTC 时间；记录关键操作者和创建/发布时间。 |

## 依赖规则

- `web`/REST Controller 只做输入校验与响应映射，调用应用服务，不承载授权决策或业务状态转换。
- `application` 编排用例、事务和模块协作；`domain` 保持业务不变量；`infrastructure` 负责 JPA、对象存储、邮件/验证等适配。
- 跨模块只能调用对方公开的应用服务/接口与 DTO；禁止直接访问其他模块 Repository、实体或私有包。
- 所有资源授权在服务端按当前认证身份、角色、班级所有权/成员关系与资源归属执行。UUID/资源 ID 不是授权凭证。
- 数据迁移通过 Flyway；生产 API 默认拒绝未认证访问。CORS、CSRF/凭证传递策略需与最终部署域名一起确定。

## 关键状态转换

- 作业：`DRAFT → PUBLISHED → CLOSED`；只有草稿可编辑核心内容。发布后的截止/提交关闭变更需有明确 API 和审计记录。
- 上传：`PENDING_UPLOAD → VALIDATED → SUBMITTED`；签名 URL 成功发放不等于提交成功。未就绪可重试；校验失败不生成提交版本；首次校验通过的 complete 原子性分配版本号并写 UTC `completedAt`；`completedAt == dueAt` 按时，只有 `completedAt > dueAt` 才逾期；重复 complete 返回原结果。
- 批改：`DRAFT → PUBLISHED`；发布记录追加不可覆盖，学生读取当前已发布记录。

## 文件安全底线

服务端生成不可预测的对象 key；不接受客户端传入任意 key 或 URL。上传签名和下载签名都绑定具体对象、用途和短过期时间。创建/完成上传、访问下载 URL 前均执行服务端对象级权限校验。complete 阶段校验对象存在、实际大小与允许类型；浏览器声明的 MIME 和文件名不可信。拒绝超限/不支持文件，不将未完成或校验失败对象暴露为提交；按策略清理孤儿对象。
